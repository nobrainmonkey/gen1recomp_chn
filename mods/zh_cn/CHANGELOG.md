# Changelog

## 0.3.1

- 修复 Red／Blue／Yellow 初始及赠送宝可梦领取台词显示英文内部名称的问题；
  同一兼容层也会把 23 号道路检查点的徽章内部名称解析为中文道具名。
- 补全攻击、防御、速度、特殊、命中率与闪避率，并覆盖升级能力窗口、
  战斗／道具动态句子、状态页、队伍页和常青市学校黑板。
- 补全招式选择、寄放队伍、飞翔目的地、奖品菜单和奖状正文等动态界面文本。
- 新增动态名称与能力／状态标签回归测试，并验证昵称恰好为 `ATTACK` 或
  宝可梦内部 ID 时不会被误翻译。

## 0.3.0

- 把简体中文剧情目录扩展为 Yellow／共享目录加 Red／Blue 专用覆盖，
  避免同一文本 ID 在不同版本中显示错误台词。
- 新增 Red 和 Blue 导入、NEW GAME 开场及游戏内回归检查。
- 保留对旧 0.1.0 版大木博士开场缺文和 `Tokens.lua` 崩溃的修复。
- 字体工具默认使用相对位置的 QuanPixel BDF，并保留 Fusion Pixel 等宽版选项。
- 重写用户优先的安装文档，补全署名、第三方许可与发布安全说明。

## 0.2.0

- 完成 Yellow 的剧情、NPC、系统、菜单和战斗文本目录。
- 加入 151 种宝可梦的中国大陆官方名称和第一世代术语表。
- 加入可重建的分页 8×8 中文字库。
